# 답안 판정 엔진 · 촬영 품질 검사

OCR 채점 파이프라인(기획서 §2, §6, §12) 중 외부 서비스 없이 동작하는 두 부분이다.

```
학생 촬영/첨부 ─▶ 촬영 품질 검사 (브라우저) ─▶ 업로드 ─▶ OCR (Google Vision, 예정) ─▶ 답안 판정 엔진 ─▶ 정답 / 오답 / 검토 필요
```

## 1. 답안 판정 엔진

| 파일 | 역할 |
| --- | --- |
| `supabase/functions/_shared/answer-judge.ts` | 판정 엔진 (순수 함수, 서버 함수·화면 공용) |
| `supabase/functions/_shared/answer-judge.test.ts` | 판정 규칙 테스트 |
| `src/components/exam-sheet/subjective/answer-tester.tsx` | 시험지 관리 › 주관식 문항 요약의 "판정 테스트" |

화면에서는 `@shared/answer-judge.ts`로 가져온다. (`tsconfig.app.json`, `vite.config.ts`의 `@shared` 별칭)

### 정규화

| 규칙 | 예 |
| --- | --- |
| 아래첨자·위첨자·전각 문자 → 일반 문자 (NFKC) | `H₂O` → `H2O`, `SO₄²⁻` → `SO42-`, `ＮａＣｌ` → `NaCl` |
| 공백 제거 (한글 띄어쓰기 차이 허용) | `산화 수` → `산화수` |
| 문장 부호 제거 (`+ - → = ( ) [ ]`는 유지) | `염화 나트륨.` → `염화나트륨` |
| 화살표·빼기표 통일 | `->`, `=>`, `⟶` → `→`, `−`, `–` → `-` |
| 이온 전하 위치 통일 (반응식 제외) | `Fe+3` → `Fe3+`, `Na1+` → `Na+` |

### 판정

| 경우 | 결과 | 이유 |
| --- | --- | --- |
| 정답과 같음 | 정답 | `exact` / `normalized` |
| 허용 표기와 같음 | 정답 | `alias` |
| 반응식: 같은 쪽 항의 순서만 다름 | 정답 | `equation` |
| 반응식: 물질은 맞고 계수가 다름 | 오답 | `coefficient` |
| 대소문자만 다름 (`nacl`, `CO`↔`Co`) | 검토 필요 | `case_mismatch` |
| 한 글자 차이 (`산회`↔`산화`) | 검토 필요 | `near_miss` |
| OCR 신뢰도 0.8 미만 | 검토 필요 (자동 확정 안 함) | `low_confidence` |
| 읽은 글자 없음 | 검토 필요 | `empty` |
| 그 외 | 오답 | `mismatch` |

- 한 글자 차이 규칙 때문에 `양이온`↔`음이온`처럼 실제로 틀린 답도 검토 필요로 갈 수 있다. 오답을 자동 확정하지 않고 선생님이 본다.
- 시험지 요약(`summarizeJudgements`)은 검토 필요를 아직 정답으로 세지 않고, 검토 필요가 하나라도 있으면 바로 확정할 수 없다.

## 2. 촬영 품질 검사

| 파일 | 역할 |
| --- | --- |
| `src/lib/photo-quality.ts` | 밝기·대비·선명도·빛 반사·해상도 계산과 판정 |
| `src/lib/photo-quality.test.ts` | 판정 규칙 테스트 (합성 이미지) |
| `src/components/upload/photo-dropzone.tsx` | 사진 첨부: 고르면 바로 미리보기·검사 |
| `src/components/upload/camera-panel.tsx` | 실시간 촬영: 0.5초마다 검사, 연속 3번 통과하면 자동 촬영 |
| `src/components/upload/photo-quality-report.tsx` | 항목별 결과 표시 |

분석할 때 사진을 긴 변 800px로 줄여서 계산한다. 기준값은 `PHOTO_THRESHOLDS`에 모여 있으니 실제 촬영본으로 보정한다.

| 항목 | 계산 | 기준 | 결과 |
| --- | --- | --- | --- |
| 밝기 | 평균 밝기 | 70 미만 / 235 초과 | 오류 (너무 어둡다 / 밝다) |
| 선명도 | 라플라시안 분산 | 100 미만 | 오류 (흔들림) |
| 빛 반사 | 밝기 250 이상 픽셀 비율 | 2% 이상 경고, 4% 이상 오류 | 경고 / 오류 |
| 글씨 대비 | 밝기 표준편차 | 25 미만 | 경고 |
| 해상도 | 원본 짧은 변 | 1000px 미만 | 경고 |

- 오류가 하나라도 있으면 `업로드 저장`을 막고 다시 찍도록 안내한다. 경고는 안내만 한다.
- 정렬 마커(네 모서리) 검출과 원근 보정은 OpenCV를 붙일 때 추가한다. (기획서 §11)
